# دليل بوت تيليجرام الشامل 🤖
### Telegram Bot Architecture, Setup & Command Guide — TaskTracker Studio

يوفر نظام **TaskTracker Studio** مساعداً ذكياً متكاملاً عبر تيليجرام يعمل بتقنية الـ Long-Polling مع منظومة حماية حديدية (Zero-Trust Security Barrier). يتيح لك إدارة ومتابعة مشروعاتك البرمجية، تسجيل المهام صوتياً وكتابياً، التحكم في المهام بأزرار تفاعلية، استخراج النسخ الاحتياطية الحية لقاعدة البيانات، واستلام تنبيهات الأمان الفورية.

## 🌟 1. المميزات الرئيسية للبوت

* **إدارة المهام اللحظية:** استعلام فوري بحالة النظام، استعراض المهام المعلقة، وإضافة مهام جديدة تظهر على لوحة التحكم على الويب في نفس الثانية.
* **تسجيل المهام الصوتية (Voice Notes):** تسجيل فويس نوت مباشرة من الموبايل؛ يُحولها البوت فوراً إلى مهمة طارئة (P1) مع توثيق مدتها بالثواني وتقديم أزرار للبدء فيها أو إنجازها.
* **أزرار تفاعلية بنقرة واحدة (Inline Keyboards):** أزرار `[▶️ بدء]`, `[✅ تم]`, `[🗑️ حذف]` تظهر أسفل كل مهمة في تيليجرام لتغيير حالتها في قاعدة البيانات مباشرة.
* **تنظيف المرفقات الذكي (Auto-Cleanup):** عند الضغط على `[✅ تم]` أو `[🗑️ حذف]`، يقوم النظام بمسح أي صور أو مرفقات تابعة للمهمة من القرص الصلب للسيرفر تلقائياً لتوفير المساحة.
* **نسخ احتياطي فوري ومجدول (Database Backups):** إرسال ملف قاعدة البيانات `workmanager.db` كملف قابل للتحميل المباشر بعد تنفيذ WAL Checkpoint لضمان عدم فقدان أي معاملة.
* **جدار أمني صارم (Zero-Trust Barrier):** صد أي محاولة تحدث من مستخدم غير مصرح به، وإرسال تقرير للمالك بحساب المتسلل والـ ID الخاص به.
* **فك الحظر الأمني:** رفع الحظر عن عناوين IP المحظورة بضغطة زر أو أمر مباشر.

## 🚀 2. دليل الإعداد السريع لمن ينسخ المستودع (Step-by-Step Setup)

إذا قمت بنسخ مستودع TaskTracker (Fork / Clone) وترغب في ربط بوت تيليجرام خاص بك، اتبع الخطوات البسيطة التالية:

### الخطوة 1: إنشاء بوت جديد عبر BotFather
1. افتح تطبيق تيليجرام وابحث عن الحساب الرسمي: **`@BotFather`**.
2. أرسل الأمر: `/newbot`.
3. اكتب اسماً للبوت (مثال: `My Work Tracker`).
4. اختر معرّف يوزر للبوت ينتهي بكلمة `bot` (مثال: `my_worktracker_bot`).
5. سيعطيك BotFather رمز الوصول المميز (**HTTP API Token**)، انسخه واحفظه؛ سيكون بهذا الشكل:
   ```text
   1234567890:ABCdefGhIJKlmNoPQRstuVWXyz-1234567
   ```

### الخطوة 2: إنشاء الجروب الخاص واستخراج `TELEGRAM_CHAT_ID`
1. أنشئ جروب تيليجرام جديد (Private Group)، وسمّه مثلاً: `Task_Backups`.
2. أضف بوتك الجديد إلى هذا الجروب، وقم بترقيته إلى **مسؤول (Administrator)**.
3. لمعرفة معرّف الجروب (`Chat ID`):
   * أضف البوت المساعد `@RawDataBot` أو `@userinfobot` مؤقتاً للجروب، وسيرسل لك رسالة تحتوي على الـ `id` (يبدأ عادةً برقم سالب مثل `-1001234567890`).
   * **أو بدون بوتات وسيطة:** أرسل أي رسالة نصية داخل الجروب، ثم افتح في المتصفح الرابط التالي (مع استبدال التوكن بتوكن بوتك):
     ```text
     https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
     ```
     ابحث في النص الناتج عن `"chat":{"id": -100xxxxxxxxxx}` وانسخ هذا الرقم بالكامل مع علامة السالب.

### الخطوة 3: ضبط متغيرات البيئة في ملف `.env`
افتح ملف `.env` في جذر المشروع وقم بتعيين المتغيرات:
```env
# توكن البوت المستخرج من BotFather
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGhIJKlmNoPQRstuVWXyz-1234567"

# معرّف الجروب الخاص للنسخ الاحتياطي والتنبيهات
TELEGRAM_CHAT_ID="-1001234567890"

# رمز الدخول السري المكون من 6 أرقام لنظامك (يُستخدم أيضاً لتوثيق الخاص)
APP_PIN="123456"

# رابط موقعك أو السيرفر الخاص بك
APP_DOMAIN="https://tasktracker.yourdomain.com"
```

### الخطوة 4: تشغيل التطبيق وتوثيق حسابك الشخصي
1. شغّل التطبيق (عبر Docker أو محلياً `npm run dev` أو `npm start`).
2. يبدأ البوت تلقائياً الاستماع للأوامر بتقنية الـ Long-Polling مع بدء السيرفر.
3. داخل الجروب: البوت يعمل فوراً وبشكل موثوق ومباشر.
4. في الشات الخاص مع البوت: افتح الشات مع بوتك واكتب الأمر لمرة واحدة فقط لتوثيق حسابك كمسؤول معتمد:
   ```bash
   /auth <YOUR_APP_PIN>
   ```
   *(مثال: `/auth 123456`)*.

## 🛡️ 3. معمارية الأمان المزدوجة (Zero-Trust Security Architecture)

يعتمد البوت على استراتيجية عزل صارمة لضمان حظر المتطفلين تماماً:

```
[ وارد تيليجرام ]
       │
       ▼
 هل الرسالة من الجروب الموثوق TELEGRAM_CHAT_ID؟
       ├───────► نعم ──► [ تنفيذ الأمر فوراً بكامل الصلاحيات ]
       ▼ لا
 هل أمر توثيق: /auth <PIN>؟
       ├───────► الـ PIN مطابق؟ ──► [ حفظ ID المستخدم في authorized_telegram_users.json واعتماده كمسؤول للأبد ]
       │                         └──► [ رفض + إشعار أمني في الجروب بوجود محاولة تخمين خاطئة ]
       ▼ لا
 هل معرف المستخدم موجود في القائمة البيضاء (Whitelist)؟
       ├───────► نعم ──► [ تنفيذ الأمر فوراً ]
       ▼ لا
 [ رفض فوري + طرد المتطفل + إرسال تنبيه أمني عاجل للمالك في الجروب بحساب المتسلل والـ ID ورسالته ]
```

### ملف القائمة البيضاء (`authorized_telegram_users.json`)
عند نجاح التوثيق بـ `/auth`، يُسجل الـ Telegram ID الخاص بك في ملف `prisma/authorized_telegram_users.json`. هذا الملف محمي على السيرفر ويستمر عبر عمليات إعادة التشغيل، مما يجعل شات الخاص حصرياً لك بنسبة 100%.

## 📋 4. مرجع الأوامر الكامل والأنماط (Commands & Patterns)

| الأمر | النمط والصيغة | الوظيفة والنتيجة |
| :--- | :--- | :--- |
| **`/start`** أو **`/help`** | `/help` | عرض دليل الاستخدام وقائمة الأوامر وروابط المنصة. |
| **`/status`** | `/status` | تقرير لحظي بحالة النظام: عدد المشاريع، مهام الطوارئ P1، المهام قيد التنفيذ، والمنجز اليوم. |
| **`/tasks`** | `/tasks` | استعراض أبرز المهام المعلقة مع **أزرار تفاعلية فورية** لكل مهمة (`بدء`, `تم`, `حذف`). |
| **`/add`** | `/add <عنوان المهمة> [P1\|P2\|P3]` | إضافة مهمة فورية وربطها بالمشروع النشط وعرض أزرار التحكم بها. |
| **تسجيل صوتي** | *(إرسال فويس نوت مباشرة)* | إدراج الفويس نوت فوراً كمهمة طارئة (P1) مع توثيق مدتها بالثواني. |
| **`/backup`** | `/backup` | أخذ لقطة فورية من قاعدة البيانات `workmanager.db` وإرسالها كملف قابل للتحميل في الشات. |
| **`/unblock`** | `/unblock <IP>` | فك الحظر الأمني عن أي IP تم حظره بعد 3 محاولات خاطئة للـ PIN. |
| **`/auth`** | `/auth <PIN>` | توثيق حسابك في الشات الخاص واعتماده كمسؤول مصرح له. |

### أنماط استخدام الأمر `/add`:
* **إضافة مهمة طارئة قصوى (P1):**
  ```bash
  /add عطل في سيرفر الداتابيز الرئيسي P1
  ```
* **إضافة مهمة تطوير أساسية (P2 الافتراضية):**
  ```bash
  /add عمل صفحة تصدير الفواتير اكسيل
  ```
* **إضافة تعديل أو دعم سريع (P3):**
  ```bash
  /add تغيير لون زر الحفظ في شاشة الدخول P3
  ```

## ⚡ 5. الأزرار التفاعلية والتحكم السريع (Inline Action Buttons)

عند طلب `/tasks` أو إضافة مهمة عبر `/add` أو إرسال فويس نوت، يرفق البوت أزرار تفاعلية (Inline Keyboard) أسفل كل مهمة:

```
[🔴 P1] عطل في سيرفر الداتابيز الرئيسي
📁 المشروع: كاش إكس
┌──────────────┬──────────────┬──────────────┐
│   ▶️ بدء     │    ✅ تم     │   🗑️ حذف    │
└──────────────┴──────────────┴──────────────┘
```

1. **زر `[▶️ بدء]` (`start_<id>`):**
   * ينقل حالة المهمة في قاعدة البيانات إلى `in_progress`.
   * تظهر فوراً في لوحة التحكم بلون مميز ونابض بالنشاط.
2. **زر `[✅ تم]` (`done_<id>`):**
   * يحدد المهمة كـ `done` ويُسجل وقت الإنجاز `completedAt`.
   * **الحذف التلقائي للمرفقات:** يقوم بحذف أي صور مرفقة بالمهمة من السيرفر فوراً لتحرير المساحة.
3. **زر `[🗑️ حذف]` (`del_<id>`):**
   * يحذف المهمة نهائياً من قاعدة البيانات مع مسح صورها المرفقة.

## 🎙️ 6. تسجيل المهام بالصوت (Voice-to-Task Capture)

إذا كنت تقود سيارتك أو في الخارج ولا تملك وقتاً للكتابة:
1. افتح شات البوت (أو الجروب الخاص).
2. اضغط مطولاً على زر الميكروفون وسجل ملاحظتك الصوتية ثم أرسلها.
3. يقوم البوت فوراً بالآتي:
   * استلام الفويس نوت وقراءة مدتها بالثواني.
   * إدراجها فوراً في عمود **الطوارئ اليومي (P1)** تحت المشروع النشط بعنوان:
     `🎙️ طلب صوتي مسجل (X ث)` أو بالنص المكتوب في الـ (Caption) إن وُجد.
   * إرسال رسالة تأكيد فورية مع أزرار التحكم `[▶️ بدء]`, `[✅ تم]`, `[🗑️ حذف]`.

## ⏰ 7. الخدمات الآلية والتنبيهات المجدولة (Automations & Crons)

### 1. النسخ الاحتياطي التلقائي اليومي (Daily Auto-Backup)
* يعمل كرون مجدول تلقائياً في السيرفر كل يوم الساعة **4:00 صباحاً**.
* يقوم بعمل `PRAGMA wal_checkpoint(TRUNCATE)` لدمج المعاملات المعلقة في ملف الداتابيز `workmanager.db`.
* يُرسل ملف النسخة الاحتياطية تلقائياً إلى جروب `TELEGRAM_CHAT_ID` بعنوان:
  `workmanager-backup-YYYY-MM-DD.db`.

### 2. التنبيهات الأمنية والحظر التلقائي (Security Alerts)
* إذا تجاوز أي شخص 3 محاولات خاطئة لإدخال الـ PIN في المتصفح، يقوم السيرفر بفرض حظر دائم على عنوان الـ IP الخاص به (Hard IP Ban).
* يُرسل البوت فوراً رسالة تحذيرية في الجروب:
  ```text
  🚨 تنبيه أمني - نظام TaskTracker
  ⚠️ تم حظر عنوان IP بشكل دائم: 197.35.x.x
  🔢 السبب: تجاوز 3 محاولات دخول خاطئة لكود الـ PIN.
  🔓 لفك الحظر عن هذا الـ IP اكتب:
  /unblock 197.35.x.x
  ```

## 🔧 8. استكشاف الأخطاء الشائعة وحلها (Troubleshooting)

### س: البوت لا يستجيب لأي أمر في الشات الخاص؟
* **السبب:** لم يتم توثيق حسابك برقم الـ PIN، فالبوت يعتبرك متطفلاً ويصدك أمنياً.
* **الحل:** أرسل للبوت: `/auth <YOUR_APP_PIN>` (مثال: `/auth 123456`).

### س: البوت لا يرسل تنبيهات للجروب؟
* **السبب:** إما أن `TELEGRAM_CHAT_ID` غير صحيح في `.env` (تأكد من وجود علامة السالب `-100...`)، أو أن البوت لم تتم ترقيته إلى **مسؤول (Administrator)** في الجروب.
* **الحل:** تأكد من إعطاء البوت صلاحيات الإدارة في الجروب.

### س: كيف أغيّر رمز الـ PIN أو التوكن مستقبلاً؟
* عدّل القيمة في ملف `.env` على السيرفر، ثم أعد تشغيل التطبيق (`docker compose restart` أو `npm restart`).
* إذا غيرت الـ PIN، يمكنك إعادة توثيق أي حساب جديد بنفس الخطوة البسيطة: `/auth <NEW_PIN>`.
