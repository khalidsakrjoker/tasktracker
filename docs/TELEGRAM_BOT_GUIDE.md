# دليل التحكم والربط مع بوت تيليجرام 🤖
### Telegram Bot Command & Security Guide — TaskTracker Studio

يوفر نظام **TaskTracker Studio** بوت تيليجرام ذكياً لإدارة ومتابعة مهامك ومشروعاتك البرمجية واستلام التنبيهات الأمنية والنسخ الاحتياطية آلياً.

---

## 🔒 1. منظومة الأمان والتحكم (Security & Whitelist)

لحماية بياناتك ومشروعاتك من أي وصول غير مصرح به:
1. **الجروب المخصص (`TELEGRAM_CHAT_ID`):**
   - يُنصح بإنشاء جروب تيليجرام خاص (Private Group) مخصص للنسخ الاحتياطي لا يضم أحداً إلا أنت وبوتك، وتعيين معرّفه في متغير البيئة `TELEGRAM_CHAT_ID`.
   - جميع الأوامر المرسلة داخل هذا الجروب معتمدة وموثوقة بنسبة 100% لأن الجروب مغلق بالكامل ولا يستطيع أحد الانضمام إليه إلا بدعوة شخصية منك.
2. **الشات الخاص المباشر مع البوت:**
   - **مغلق أمنياً بوجه أي شخص غريب:** أي مستخدم غريب يبحث عن يوزر البوت ويحاول إرسال أوامر، يتم صده فوراً وحرمانه من أي رد، وإرسال تنبيه أمني فوري في الجروب ببيانات حسابه والـ ID الخاص به.
   - **اعتماد حسابك الشخصي فقط:** لتفعيل التحكم من الشات الخاص لحسابك الشخصي لمرة واحدة للأبد، ترسل للبوت في الخاص:
     ```bash
     /auth <YOUR_APP_PIN>
     ```
     (حيث `<YOUR_APP_PIN>` هو كود الـ PIN السري الخاص بنظامك والمحدد في ملف `.env`). بمجرد إرسالها، يعتمد البوت حسابك الشخصي فقط كمسؤول للنظام (`Admin Verified`) ولن يقبل أي أوامر في الخاص من أي حساب آخر على تيليجرام.

## 📋 2. جدول الأوامر التفاعلية الكاملة (Bot Commands)

| الأمر | طريقة الاستخدام | الوظيفة والنتيجة |
| :--- | :--- | :--- |
| **`/start`** أو **`/help`** | `/help` | عرض دليل الاستخدام وقائمة الأوامر التفاعلية وروابط النظام. |
| **`/status`** | `/status` | تقرير لحظي فوري بحالة النظام: عدد المشروعات النشطة، مهام الطوارئ `P1`، المهام المعلقة، وما تم إنجازه اليوم. |
| **`/tasks`** | `/tasks` | استعراض أهم وأخطر المهام المعلقة حالياً مرتبة حسب الأولوية (`P1` ثم `P2` ثم `P3`) مع اسم المشروع التابع لكل مهمة. |
| **`/add`** | `/add <عنوان المهمة> [P1\|P2\|P3]` | إضافة مهمة جديدة فوراً للنظام من تليجرام في ثانيتين وتظهر فوراً على الداشبورد على الويب! |
| **`/backup`** | `/backup` | استخراج نسخة احتياطية فورية وحية لقاعدة البيانات (`workmanager.db`) بعد عمل Checkpoint للـ WAL وإرسالها لك كملف قابل للتحميل المباشر. |
| **`/unblock`** | `/unblock <IP>` | فك الحظر الأمني عن أي عنوان IP تم حظره بعد تجاوز محاولات إدخال الـ PIN الخاطئة (مثال: `/unblock 192.168.1.50`). |
| **`/auth`** | `/auth <PIN>` | توثيق واعتماد حسابك الشخصي في الشات الخاص برقم الـ PIN السري (استخدام لمرة واحدة فقط). |

## 💡 3. أمثلة عملية لاستخدام الأوامر

### أ) إضافة مهمة طارئة P1:
```bash
/add تصليح مشكلة إيقاف السيرفر فجأة P1
```
* **النتيجة:** تسجل المهمة فوراً بالأولوية القصوى `P1` تحت المشروع الافتراضي وتظهر على الويب في عمود الطوارئ فوراً.

### ب) إضافة مهمة تطوير عادية P2:
```bash
/add برمجة شاشة تصدير التقارير إلى PDF
```
* **النتيجة:** تسجل المهمة تلقائياً بأولوية `P2` (بناء وتطوير أساسي).

### ج) فك الحظر عن عنوان IP:
```bash
/unblock 41.233.10.85
```
* **النتيجة:** يتم رفع الحظر الأمني عن هذا الآي بي فوراً ويصبح بإمكانه فتح النظام وتسجيل الدخول مجدداً.

### د) طلب نسخة احتياطية فورية:
```bash
/backup
```
* **النتيجة:** يُرسل البوت ملف `workmanager-backup-YYYY-MM-DD.db` جاهزاً للتحميل على جهازك.

## ⏰ 4. الخدمات الآلية المجدولة (Automations)

1. **النسخ الاحتياطي التلقائي اليومي:**
   - كل يوم في تمام الساعة **4:00 صباحاً (بتوقيت السيرفر)** يقوم النظام تلقائياً بإنشاء نسخة احتياطية وإرسالها إلى جروب `Task_BU`.
2. **التنبيهات الأمنية الفورية:**
   - إذا حاول أي شخص إدخال كود PIN خاطئ 3 مرات متتالية، يتم حظر الـ IP بتاعه فوراً، ويصلك إشعار فوري في الجروب بعنوان الـ IP ورابط فك الحظر.
   - إذا حاول أي شخص غريب التحدث مع البوت في الشات الخاص، يصلك إشعار فوري بحسابه والـ ID الخاص به.
